# Home Key Clean

Static site for HomeKeyClean.com: homepage booking funnel, service and city landing pages, client matches page and pro portal.

- `index.html` homepage and booking funnel
- `services/`, `areas/` landing pages (10 services, 218 cities)
- `matches/` client results page, `pro/` pro portal (demo data stored in the browser)
- `store.js`, `matches.js`, `pro.js`, `site.css`, `app.css` shared code and styles
- `sitemap.xml`, `robots.txt`, `404.html`, `netlify.toml`, `CNAME`, `.nojekyll`

No build step. Publish the repository root as-is.
